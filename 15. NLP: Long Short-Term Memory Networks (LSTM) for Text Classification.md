# NLP: Long Short-Term Memory Networks (LSTM) for Text Classification

In **Section 12. NLP: Tokenization and Embeddings**, we introduced the first essential steps required for building a text classification system. We learned how to load and preprocess the SMS Spam Collection dataset, create training and testing datasets, convert text into numerical representations through tokenization, and transform token IDs into dense vector representations using word embeddings.

In **Section 13. NLP: Feed-Forward Neural Networks for Text Classification**, we introduced a baseline neural network model for SMS spam classification. The Feed-Forward Neural Network (FFNN) demonstrated the complete workflow of a neural text classification system, from processing word embeddings to generating the final spam/ham prediction. However, this architecture does not consider the sequential structure of text because the word order information is lost during the average pooling operation.

In **Section 14. NLP: Recurrent Neural Networks for Text Classification**, we introduced the standard (vanilla) Recurrent Neural Network (RNN) as a model designed specifically for sequential data. Unlike FFNNs, RNNs process input sequences word by word and maintain a hidden state that allows the model to capture information from previous words. This capability makes RNNs more suitable for natural language processing tasks.

However, vanilla RNNs suffer from an important limitation known as the **vanishing gradient problem**. When processing long sequences, the information stored in earlier time steps may gradually disappear during training. As a result, standard RNNs often struggle to learn long-term dependencies between words that are far apart in a sentence.

In this lecture, we will introduce the **Long Short-Term Memory network (LSTM)**, an advanced type of recurrent neural network designed to overcome the limitations of vanilla RNNs. LSTM introduces a memory mechanism that enables the network to selectively store, update, and remove information during sequence processing.

By using specialized components called **gates**, LSTM networks can decide:

* which information should be stored in memory,
* which information should be forgotten,
* and which information should be used for making predictions.

These mechanisms allow LSTMs to learn both short-term and long-term dependencies in sequential data, making them one of the most widely used architectures for natural language processing tasks before the emergence of Transformer-based models.

# 1. Limitations of Vanilla Recurrent Neural Networks (RNNs)

In the previous lecture, we introduced the **vanilla Recurrent Neural Network (RNN)** and showed how it can process sequential data such as text. Unlike Feed-Forward Neural Networks, which treat each input independently, RNNs maintain a **hidden state** that carries information from previous time steps.

## 1.1 The Vanishing Gradient Problem

The main limitation of vanilla RNNs comes from the way gradients are propagated during training.

Training a neural network requires **backpropagation through time (BPTT)**. During this process, the error gradients are propagated backward through all previous time steps to update the model parameters.

For a long sequence, the gradient calculation involves repeated multiplication through the recurrent weights. Because this multiplication is repeated many times, the gradient values can become extremely small. This problem is known as the **vanishing gradient problem**.

When gradients become very small:

* Early time steps receive almost no updates.
* The model cannot learn information from distant words.
* Important information from the beginning of a sequence may be forgotten.

For example, consider the following sentence:

```text
The movie that I watched last night with my friends was extremely amazing.
```

To classify the sentiment of this sentence, the model needs to connect:

```text
The movie
```

with

```text
amazing
```

However, these words are separated by many intermediate words. A vanilla RNN may fail to preserve the information about the beginning of the sentence while processing later words.


## 1.2 Difficulty with Long-Term Dependencies

A fundamental challenge in natural language processing is that important information is not always located close to the word being predicted.

Consider the following SMS message:

```text
Congratulations! You have been selected for a special offer. 
Your account has won a free reward.
```

The word:

```text
Congratulations
```

provides important context that this message is likely to be spam. However, after processing many additional words, a vanilla RNN may lose this information because the hidden state is continuously updated at every time step.

In contrast, short-term relationships are easier for RNNs to learn.

For example:

```text
I am very happy
```

The relationship between:

```text
very → happy
```

is close in the sequence, so the RNN can usually capture it effectively.

However, relationships such as:

```text
word at position 1 → word at position 50
```

are much more difficult for a vanilla RNN.


## 1.3 The Hidden State as a Single Memory

In a vanilla RNN, all historical information is compressed into a single hidden state vector.

The hidden state must simultaneously store:

* recent information,
* important information from previous words,
* irrelevant information that may no longer be needed.

This creates a bottleneck.

For example, consider the sentence:

```text
The smartphone, which I bought two years ago after saving money for a long time, is still working perfectly.
```

A human reader can easily understand that:

```text
smartphone → working perfectly
```

However, a vanilla RNN must store all intermediate information inside one hidden state vector. During this process, important information may be overwritten by newer information.


## 1.4 Exploding Gradients

Besides the vanishing gradient problem, RNNs can also suffer from the opposite problem: **exploding gradients**.

During backpropagation, repeated multiplication by large values can cause gradients to become extremely large.

This may lead to:

* unstable training,
* very large parameter updates,
* numerical problems during optimization.

Common techniques such as **gradient clipping** can reduce this problem, but they do not solve the fundamental limitation of the RNN architecture.


### Summary of Vanilla RNN Limitations

Although vanilla RNNs introduced an important improvement over Feed-Forward Neural Networks by enabling sequential processing, they have several limitations:

| Limitation                                 | Description                                                        |
| ------------------------------------------ | ------------------------------------------------------------------ |
| Vanishing gradients                        | Gradients become very small when propagated through long sequences |
| Difficulty learning long-term dependencies | Important information from earlier words may be forgotten          |
| Single hidden-state memory                 | All information must be compressed into one vector                 |
| Training instability                       | Exploding gradients can make optimization difficult                |


To overcome these problems, researchers introduced the **Long Short-Term Memory network (LSTM)**. LSTM extends the RNN architecture by adding a dedicated memory component and a set of gates that control how information is stored, updated, and removed.

# 2. The Motivation Behind Long Short-Term Memory (LSTM) Networks

The main motivation behind **Long Short-Term Memory (LSTM)** networks is to overcome these limitations by introducing a more effective memory mechanism. Instead of relying on a single hidden state to store all information, LSTMs use **two different memory representations** and a set of **gates** that control the flow of information through the network.

As a result, LSTMs can learn which information should be remembered, which should be forgotten, and which should be used to make predictions.

## 2.1 Memory in a Vanilla RNN

Recall that a vanilla RNN processes a sequence one word at a time. At each time step, it receives the current input and the hidden state from the previous time step, then computes a new hidden state.

The process can be illustrated as follows.

```text
Previous Hidden State (hₜ₋₁)
             │
             ▼
        +-----------+
Input ─► | RNN Cell | ─► New Hidden State (hₜ)
        +-----------+
```

The hidden state therefore has two responsibilities:

1. **Remember information** from previous words.
2. **Provide information** for making predictions at the current time step.

Using a single memory for both tasks works well for short sequences. However, as the sequence becomes longer, the hidden state is updated repeatedly, causing earlier information to gradually disappear. Consequently, the model may forget important words that appeared many time steps earlier.


## 2.2 A Better Memory System

LSTM addresses this problem by introducing **two different types of memory** instead of one:

* **Cell State (($C_t$))** – stores long-term information.
* **Hidden State (($h_t$))** – stores short-term information and serves as the output of the current time step.

The overall structure of an LSTM cell can be viewed as follows.

```text
                 +----------------------+
                 |      LSTM Cell       |
Input ─────────► |                      | ─────────► Hidden State (hₜ)
                 |                      |
                 |                      | ─────────► Cell State (Cₜ)
                 +----------------------+
```

Although both states move from one time step to the next, they play different roles.


### 2.2.1 The Cell State: Long-Term Memory

The **cell state** is the primary memory of an LSTM. It is responsible for carrying important information throughout the sequence.

You can think of the cell state as a **notebook** that travels with the network while it reads a sentence. As each new word is processed, the notebook may be updated with new information, old information may be erased, or the existing information may simply be preserved.

For example, consider the sentence

```text
The movie that I watched yesterday was absolutely fantastic.
```

After reading the word

```text
movie
```

the network may decide that this information is important and store it in the cell state.

Several words later, when it encounters

```text
fantastic
```

the cell state still contains information about the movie, allowing the model to understand that **fantastic** describes the movie.

Unlike the hidden state in a vanilla RNN, the cell state is specifically designed to preserve important information over many time steps.


### 2.2.2 The Hidden State: Working Memory

The **hidden state** has a different purpose.

Instead of storing all long-term information, it represents the information that is **most useful at the current time step**.

The hidden state serves two main functions:

* It is passed to the next LSTM cell.
* It is used by subsequent neural network layers to make predictions.

An intuitive analogy is that the hidden state represents your **current thoughts**, while the cell state acts as your **long-term notebook**.

As you read a book, your notebook contains all the important facts you have recorded. However, at any particular moment, you focus on only a small portion of those facts. Similarly, the hidden state contains only the information that is immediately relevant, while the cell state preserves important information for future use.


### 2.2.3 Why Two Memories?

Separating long-term and short-term memory makes learning much easier.

In a vanilla RNN, a single hidden state must perform both tasks simultaneously:

* remembering information over long periods,
* and providing information for the current prediction.

These two responsibilities often conflict with each other, making it difficult for the network to preserve important information across long sequences.

LSTM resolves this issue by assigning different responsibilities to two separate states:

| Memory                   | Responsibility                                                                         |
| ------------------------ | -------------------------------------------------------------------------------------- |
| **Cell State ($C_t$)**   | Stores long-term information throughout the sequence.                                  |
| **Hidden State ($h_t$)** | Represents the information needed at the current time step and is used for prediction. |

At every time step, the cell state is first updated, and the hidden state is then computed from the updated cell state.

The information flow can be summarized as follows.

```text
Previous Cell State
        │
        ▼
Update Long-Term Memory
        │
        ▼
 New Cell State
        │
        ▼
Generate Hidden State
        │
        ▼
Next Layer / Prediction
```

Thus, the **cell state acts as the primary memory**, while the **hidden state represents the current output** of the LSTM.


## 2.3 Why Are Gates Needed?

At this point, an important question arises:

> **If the cell state stores long-term information, how does the network decide what should be remembered and what should be forgotten?**

The answer lies in the **gating mechanism**.

The gates act as intelligent controllers that regulate the flow of information through the LSTM. Rather than storing every piece of information, the network learns to decide

* what information should be discarded,
* what new information should be stored,
* and what information should be exposed to the next layer.

Without these gates, the cell state would eventually accumulate irrelevant information, reducing the effectiveness of the model.

Imagine that the cell state is a notebook.

Every time the LSTM reads a new word, it asks three questions.

#### 1. Should I erase something from my notebook?

This decision is made by the **Forget Gate**.

#### 2. Should I write this new information into my notebook?

This decision is made by the **Input Gate**.

#### 3. Which parts of my notebook should I reveal to make the current prediction?

This decision is made by the **Output Gate**.

The gates enable the LSTM to maintain useful information for many time steps while discarding information that is no longer relevant.
