## 7. Choosing a Pretrained Model

The model should be selected according to the **target task**, rather than simply choosing the largest or newest architecture.

A useful decision process is:

| Target problem            | Possible pretrained models                |
| ------------------------- | ----------------------------------------- |
| Image classification      | ResNet, EfficientNet, ConvNeXt, ViT, Swin |
| Object detection          | Faster R-CNN, RetinaNet, SSD, YOLO        |
| Instance segmentation     | Mask R-CNN                                |
| Semantic segmentation     | DeepLabV3, FCN                            |
| Text classification       | BERT, RoBERTa, DistilBERT, DeBERTa        |
| Text generation           | GPT-2, T5, BART, FLAN-T5                  |
| Semantic search           | Sentence-BERT                             |
| Speech recognition        | Wav2Vec 2.0, Whisper                      |
| Audio classification      | AST                                       |
| Image-text tasks          | CLIP, BLIP, BLIP-2                        |
| Visual question answering | BLIP-2, LLaVA                             |
| Time-series forecasting   | Chronos, Chronos-2, TimesFM, PatchTST     |

## 8. Installing the Main Libraries

The required libraries depend on the type of pretrained model being used.

For computer vision:

```bash
pip install torch torchvision torchaudio
```

For NLP and many multimodal models:

```bash
pip install transformers
```

For additional computer-vision architectures:

```bash
pip install timm
```

For YOLO models:

```bash
pip install ultralytics
```

For sentence embeddings:

```bash
pip install sentence-transformers
```

For generative image models:

```bash
pip install diffusers
```

For Chronos time-series models:

```bash
pip install chronos-forecasting
```

For example, to load a pretrained ResNet50 and use it for a custom 10-class image classification task:


```Python
import torch
import torch.nn as nn
from torchvision.models import resnet50, ResNet50_Weights

weights = ResNet50_Weights.DEFAULT
model = resnet50(weights=weights)

# Replace the original classifier
num_features = model.fc.in_features
model.fc = nn.Linear(num_features, 10)

# Use the preprocessing associated with the pretrained weights
preprocess = weights.transforms()
```

> Important: The image, text and audio categories are examples of possible target applications, not categories that a model is inherently limited to. Pretrained weights provide learned features from the original training data; for a new task, you generally replace the task-specific output layer and train it, optionally fine-tuning some or all of the pretrained model.
