# 1. Multivariate Time-Series Data Preparation

In a multivariate time series, we use **multiple variables at each time step** to predict a target variable.

In our Bitcoin forecasting problem, we use four variables:

1. **Price**
2. **Volume**
3. **Number of trades**
4. **Taker buy base asset volume**

The objective is to use the historical values of these four variables to predict the future **Price**.

Therefore, our forecasting problem can be represented as:

$$
\text{Past 60 time steps} \times 4\text{ features}
\rightarrow
\text{Future Price}
$$

For example, if the window size is 60 and the horizon is 1, the model receives:

$$
X \in \mathbb{R}^{60\times4}
$$

and predicts:

$$
y \in \mathbb{R}^{1}
$$

This is called **multivariate-input, univariate-output forecasting**.

## 1.4. Splitting the Dataset

For time-series forecasting, we should preserve the chronological order of the observations.

We use the first 80% of the observations for training and the remaining 20% for testing.

```python

train_data = df.iloc[:train_size]
test_data = df.iloc[train_size:]
```

The important point is that the training period comes **before** the test period.

For example:


This prevents information from the future from being used to train the model.


## 1.5. Normalizing the Data

The four variables have very different numerical ranges.

For example, `Price`, `Volume`, and `Number of trades` may have completely different scales.

Neural networks generally work better when numerical features have comparable scales.

We therefore use **Min-Max normalization**.

The Min-Max transformation is:

$$
x' = \frac{x-x_{\min}}{x_{\max}-x_{\min}}
$$

where \(x_{\min}\) and \(x_{\max}\) are calculated from the training data.

We first create the scaler:

```python
from sklearn.preprocessing import MinMaxScaler

scaler = MinMaxScaler()
```

Then we fit it **only on the training data**:

```python
scaler.fit(train_data)
```

After that, we use the same scaler to transform both datasets:

```python
train_scaled = scaler.transform(train_data)
test_scaled = scaler.transform(test_data)
```

Here, the scaler learns the minimum and maximum value of each feature from the training data.

It is important that we **do not fit the scaler separately on the test data**. The test data must use the same transformation learned from the training data. 

This ensures that training and test data follow the same numerical scale. It also prevents information from the test set from influencing the preprocessing process.


## 1.6. Converting the Normalized Data Back to DataFrames

## 1.7. Defining the Input Features and Target

# 2. Creating Multivariate Sliding Windows

We now convert the time series into input-target pairs.

The idea is to use a fixed number of previous observations as the input.

For example:

```text
window_size = 5
horizon = 2
```

means that we use **5 historical time steps** to predict the next **2 time steps**.

For a multivariate dataset, each time step contains four features:

```text
             4 features
          ┌─────────────────────────┐
t-4       │ Price Volume Trades Buy │
t-3       │ Price Volume Trades Buy │
t-2       │ Price Volume Trades Buy │
t-1       │ Price Volume Trades Buy │
t         │ Price Volume Trades Buy │
          └─────────────────────────┘
                    ↓
                  Model
                    ↓
          Future Price values
             t+1       t+2
```

We can create these windows using the following function:

```python
import numpy as np

def create_sliding_windows(data, window_size, horizon):

    X = []
    y = []

    # Calculate the number of samples
    num_samples = len(data) - window_size - horizon + 1

    for i in range(num_samples):

        # Input window
        input_window = data[
            i : i + window_size
        ]

        # Target horizon
        target = data[
            i + window_size :
            i + window_size + horizon
        ]

        X.append(input_window)
        y.append(target)

    return np.array(X), np.array(y)
```

This function creates windows using all four variables.


# 3. Creating Training and Test Windows

For this example, we use:

```python
window_size = 5
horizon = 2
```

Then we create the windows:

```python
X_train, y_train = create_sliding_windows(
    train_scaled,
    window_size=window_size,
    horizon=horizon
)

X_test, y_test = create_sliding_windows(
    test_scaled,
    window_size=window_size,
    horizon=horizon
)
```

At this stage, the shapes are:

```text
X_train → (samples, 5, 4)
y_train → (samples, 2, 4)

X_test  → (samples, 5, 4)
y_test  → (samples, 2, 4)
```

Why does `y` contain four features?

Because our generic sliding-window function takes the next `horizon` observations of **all four variables**.

However, our actual target is only `Price`.

Since `Price` is the first column, we select column `0` from the target.

```python
# Select Price as the target

y_train = y_train[:, :, 0]
y_test = y_test[:, :, 0]
```

Now the shapes become:

```text
X_train → (samples, 5, 4)
y_train → (samples, 2)

X_test  → (samples, 5, 4)
y_test  → (samples, 2)
```

This means:

> **5 time steps × 4 input features → 2 future Price values**

For the actual forecasting experiment with `window_size = 60` and `horizon = 1`, the shapes become:

```text
X_train → (samples, 60, 4)
y_train → (samples, 1)

X_test  → (samples, 60, 4)
y_test  → (samples, 1)
```

# 5. Creating PyTorch DataLoaders

Finally, we create PyTorch `DataLoader` objects.

```python
from torch.utils.data import TensorDataset, DataLoader

def create_data_loaders(
    X_train,
    y_train,
    X_test,
    y_test,
    batch_size=128
):

    # Create TensorDatasets
    train_dataset = TensorDataset(
        X_train,
        y_train
    )

    test_dataset = TensorDataset(
        X_test,
        y_test
    )

    # Create DataLoaders
    train_loader = DataLoader(
        train_dataset,
        batch_size=batch_size,
        shuffle=False
    )

    test_loader = DataLoader(
        test_dataset,
        batch_size=batch_size,
        shuffle=False
    )

    return train_loader, test_loader
```

We can create the DataLoaders using:

```python
train_loader, test_loader = create_data_loaders(
    X_train_tensor,
    y_train_tensor,
    X_test_tensor,
    y_test_tensor,
    batch_size=128
)
```

We use:

```python
shuffle=False
```

because this is time-series data and we want to preserve the chronological order of the samples.
