# 1. Time-Series Forecasting Using RNN

In the previous lecture, we built a simple **Feedforward Neural Network (FFNN)** for Bitcoin price forecasting.

The FFNN receives a fixed window of historical closing prices and uses fully connected layers to predict the next price.

However, time-series data has an important characteristic: **the order of observations matters**.

For example:

```text
Price₁ → Price₂ → Price₃ → Price₄ → Price₅
```

The relationship between these observations contains useful temporal information.

A **Recurrent Neural Network (RNN)** is designed specifically to process sequential data and maintain information from previous time steps.


## 1.1 Why Use RNN for Time Series?

Consider the following Bitcoin closing prices:

```text
[95000, 96200, 94800, 97100, 98000, 97500, 98900]
```

When predicting the next price, we are interested not only in the individual values but also in their **sequence**.

An RNN processes the observations sequentially:

```text
95000 → RNN → h₁
             ↓
96200 → RNN → h₂
             ↓
94800 → RNN → h₃
             ↓
97100 → RNN → h₄
             ↓
98000 → RNN → h₅
             ↓
97500 → RNN → h₆
             ↓
98900 → RNN → h₇
             ↓
          Prediction
```

At each time step, the RNN receives:

* the current observation,
* the hidden state from the previous time step.

Therefore, information can be carried from earlier observations to later observations.


## 1.2 Basic Idea of an RNN

At each time step, an RNN performs a calculation similar to:

$$
h_t = f(W_xx_t + W_hh_{t-1} + b)
$$

where:

* ($x_t$) = input at time step ($t$),
* ($h_t$) = current hidden state,
* ($h_{t-1}$) = previous hidden state,
* ($W_x$) = weights for the current input,
* ($W_h$) = weights for the previous hidden state,
* ($b$) = bias,
* ($f$) = activation function, commonly `tanh`.

The important idea is:

> The current hidden state depends on both the current input and information carried from previous time steps.

Conceptually:

```text
             Previous Hidden State
                     │
                     ▼
Current Input ───►  RNN  ───► Current Hidden State
                     │
                     ▼
                  Output
```


## 1.3 Input Shape for an RNN

This is an important difference between our previous FFNN and the RNN.

For the FFNN, the input could have the shape:

```text
(batch_size, window_size)
```

For example:

```text
(128, 60)
```

An RNN expects a sequence dimension and a feature dimension:

```text
(batch_size, window_size, input_size)
```

For our univariate time series:

```text
(batch_size, window_size, 1)
```

For example:

```text
(64, 60, 1)
```

**Because we are using only the Bitcoin closing price, the number of features is:**

```python
input_size = 1
```

## 1.4 RNN Architecture

We can build the following architecture:

```text
Input
(batch_size, window_size, 1)
            │
            ▼
          RNN
      hidden_size=128
            │
            ▼
    Last Hidden State
            │
            ▼
      Linear Layer
       128 → 1
            │
            ▼
      Predicted Price
```

The RNN layer processes the complete input sequence.

The final time step is then passed to a linear layer to produce the predicted Bitcoin price.



# 2. Creating the RNN Model

We can implement the model using PyTorch.

```python
import torch
import torch.nn as nn
```

The model:

```python
class RNNModel(nn.Module):

    def __init__(
        self,
        input_size=1,
        hidden_size=128,
        horizon=1
    ):
        super().__init__()

        self.rnn = nn.RNN(
            input_size=input_size,
            hidden_size=hidden_size,
            num_layers = 1,   # Number of RNN layers
            batch_first=True
        )

        self.fc = nn.Linear(
            hidden_size,
            horizon
        )


    def forward(self, x):

        # RNN output
        output, hidden = self.rnn(x)

        # Select the output from
        # the last time step
        output = output[:, -1, :]

        # Output layer
        output = self.fc(output)

        return output
```


**The important part is:**

```python
self.rnn = nn.RNN(
    input_size=input_size,
    hidden_size=hidden_size,
    batch_first=True
)
```

### `input_size`

```python
input_size = 1
```

because our dataset has only one feature:

```text
Close Price
```

### `hidden_size`

```python
hidden_size = 128
```

This specifies the size of the hidden state.

The RNN therefore maintains a hidden representation containing 128 values at each time step.

### `batch_first=True`

We use:

```python
batch_first=True
```

so PyTorch expects:

```text
(batch_size, window_size, input_size)
```

rather than:

```text
(window_size, batch_size, input_size)
```

This makes the input representation easier to understand.


## 2.1 Why Do We Use the Last Time Step?

The RNN produces an output for every time step.

The output tensor has the shape:

```text
(batch_size, window_size, hidden_size)
```

For example:

```text
(64, 60, 128)
```

For next-step forecasting, we can use the output from the **last time step**:

```python
output = output[:, -1, :]
```

The shape becomes:

```text
(64, 128)
```

Then the linear layer converts:

```text
128 → 1
```

giving:

```text
(64, 1)
```

which represents one predicted future price for each sequence.

## 4.6 Predicting the Next Bitcoin Price

Our previously created prediction function can also be reused, but there is one important difference.

The RNN requires the input shape:

```text
(1, window_size, 1)
```

rather than:

```text
(1, window_size)
```

Therefore, we should create an RNN-specific prediction function:

```python
def predict_next_price_RNN(
    model,
    data,
    window_size
):
    """
    Predict the next value using an RNN.
    """

    # Set model to evaluation mode
    model.eval()

    # Get the latest window
    input_data = data[-window_size:]

    # Convert to NumPy
    input_data = np.asarray(
        input_data,
        dtype=np.float32
    )

    # Add sequence feature dimension
    input_tensor = torch.tensor(
        input_data,
        dtype=torch.float32
    ).reshape(
        1,
        window_size,
        1
    )

    # Move to device
    input_tensor = input_tensor.to(device)

    # Make prediction
    with torch.no_grad():

        prediction = model(
            input_tensor
        )

    # Return a single value
    return prediction.item()
```

```python

    model=model_RNN,
    data=close_prices,
    window_size=window_size
)

print(
    f"Predicted next Bitcoin closing price: "
    f"${next_price_RNN:,.2f}"
)
```
