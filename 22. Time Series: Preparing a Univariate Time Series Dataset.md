# 1. Preparing a Univariate Time Series Dataset

Before training a deep-learning model, we need to prepare the Bitcoin dataset in a suitable format.

Our used dataset contains several columns:

```text
Open Time | Open | High | Low | Close | Volume | Close Time | ...
```

For our first forecasting model, we will create a **univariate time series** using only the Bitcoin **closing price**.

However, we also keep the **time information** because each closing price must remain associated with its corresponding point in time.

Our final dataset will therefore contain:

```text
Date/Time | Close
```

For example:

```text
Date/Time                    Close
---------------------------------------
2021-01-01 00:00:00          28961.66
2021-01-01 00:01:00          29009.91
2021-01-01 00:02:00          28989.30
2021-01-01 00:03:00          28982.69
2021-01-01 00:04:00          28975.65
```

Although the dataset contains two columns, this is still considered a **univariate time series**.

The reason is that `Date/Time` represents the **time index**, while `Close` is the only numerical variable used as input and target for forecasting.

Conceptually:

```text
Time ───────────────────────────►

t₁        t₂        t₃        t₄        t₅
│         │         │         │         │
28961.66  29009.91  28989.30  28982.69  28975.65
```

The forecasting model learns from the sequence of `Close` prices.


# 2. Loading the Dataset

First, we import the Pandas library and load the CSV file:

```python
import pandas as pd

# Load the Bitcoin dataset
df = pd.read_csv("bitcoin.csv")
```

By default, Pandas interprets the first row of the CSV file as the **header**.

For example, if the CSV file starts with:

```text
Open Time,Open,High,Low,Close,Volume,...
1609460000000,28923.63,28961.66,28913.12,28961.66,27.457032,...
```

Pandas automatically uses:

```text
Open Time
Open
High
Low
Close
Volume
```

as column names.

The actual observations start from the second row.

We can inspect the dataset using:

```python
df.head()
```

We can also display the names of all columns:

```python
print(df.columns)
```

## 2.1 Selecting the Required Columns

The original dataset contains several variables, but we only need:

* `Open Time`
* `Close`

The `Open Time` column identifies when each observation occurred, while the `Close` column contains the Bitcoin closing price.

We can select these two columns as follows:

```python
df = df[["Open Time", "Close"]]
```

Now the DataFrame contains only:

```text
Open Time           Close
--------------------------------
1609460000000       28961.66
1609460060000       29009.91
1609460120000       28989.30
1609460180000       28982.69
1609460240000       28975.65
```

## 2.2 Converting the Timestamp to Date and Time

In our dataset, the `Open Time` column contains Unix timestamps measured in **milliseconds**.

For example:

```text
1609460000000
```

may be displayed in Excel as:

```text
1.60946E+12
```

This is simply scientific notation and represents the same timestamp.

To convert these timestamps into a readable date and time format, we use `pd.to_datetime()`:

```python
df["Open Time"] = pd.to_datetime(
    df["Open Time"],
    unit="ms"
)
```

The argument:

```python
unit="ms"
```

tells Pandas that the timestamps are measured in **milliseconds**.

After conversion, the data looks like:

```text
Open Time                    Close
----------------------------------------
2021-01-01 00:00:00          28961.66
2021-01-01 00:01:00          29009.91
2021-01-01 00:02:00          28989.30
2021-01-01 00:03:00          28982.69
2021-01-01 00:04:00          28975.65
```

The timestamps show that consecutive observations are separated by one minute. Therefore, this dataset represents a **one-minute time series**.


## 2.3 Renaming the Time Column

For simplicity, we can rename `Open Time` to `Date`:

```python
df = df.rename(
    columns={"Open Time": "Date"}
)
```

The resulting dataset is:

```text
Date                         Close
---------------------------------------
2021-01-01 00:00:00          28961.66
2021-01-01 00:01:00          29009.91
2021-01-01 00:02:00          28989.30
2021-01-01 00:03:00          28982.69
2021-01-01 00:04:00          28975.65
```


## 2.4 Setting the Date as the Time Index

In time-series analysis, it is often useful to use the date or timestamp as the **index** of the DataFrame.

We can do this using:

```python
df.set_index("Date", inplace=True)
```

Now the dataset has the following structure:

```text
                          Close
Date
2021-01-01 00:00:00    28961.66
2021-01-01 00:01:00    29009.91
2021-01-01 00:02:00    28989.30
2021-01-01 00:03:00    28982.69
2021-01-01 00:04:00    28975.65
```

The date is no longer treated as an ordinary column. Instead, it becomes the **time index** that identifies the chronological position of each observation.

This is useful for:

* preserving the chronological order,
* visualizing the time series,
* checking the sampling frequency,
* splitting the data chronologically,
* resampling the data later if necessary.


## 2.5 Complete Data Preparation Code

The complete preparation process can be written as follows:

```python
import pandas as pd

# Load the Bitcoin dataset
df = pd.read_csv("bitcoin.csv")

# Keep only the timestamp and closing price
df = df[["Open Time", "Close"]]

# Convert the Unix timestamp from milliseconds to datetime
df["Open Time"] = pd.to_datetime(
    df["Open Time"],
    unit="ms"
)

# Rename the time column
df = df.rename(
    columns={"Open Time": "Date"}
)

# Set the date as the time-series index
df.set_index("Date", inplace=True)

# Display the first five observations
print(df.head())
```

The final result is a clean univariate time series:

```text
                          Close
Date
2021-01-01 00:00:00    28961.66
2021-01-01 00:01:00    29009.91
2021-01-01 00:02:00    28989.30
2021-01-01 00:03:00    28982.69
2021-01-01 00:04:00    28975.65
```

Therefore, the model receives historical closing prices:

```text
[x₁, x₂, x₃, ..., xₜ]
```

and learns to predict future closing prices:

```text
[xₜ₊₁, xₜ₊₂, ...]
```
