# 1. Preparing a Univariate Time Series Dataset

Before training a deep-learning model, we need to prepare the Bitcoin dataset in a suitable format.

Our used dataset contains several columns:

```text
Open Time | Open | High | Low | Close | Volume | Close Time | ...
```

For our first forecasting model, we will create a **univariate time series** using only the Bitcoin **closing price**.

However, we also keep the **time information** because each closing price must remain associated with its corresponding point in time.

Our final dataset will therefore contain:

```text
Date/Time | Close
```

For example:

```text
Date/Time                    Close
---------------------------------------
2021-01-01 00:00:00          28961.66
2021-01-01 00:01:00          29009.91
2021-01-01 00:02:00          28989.30
2021-01-01 00:03:00          28982.69
2021-01-01 00:04:00          28975.65
```

Although the dataset contains two columns, this is still considered a **univariate time series**.

The reason is that `Date/Time` represents the **time index**, while `Close` is the only numerical variable used as input and target for forecasting.

Conceptually:

```text
Time ───────────────────────────►

t₁        t₂        t₃        t₄        t₅
│         │         │         │         │
28961.66  29009.91  28989.30  28982.69  28975.65
```

The forecasting model learns from the sequence of `Close` prices.

## 2.2 Converting the Timestamp to Date and Time

In our dataset, the `Open Time` column contains Unix timestamps measured in **milliseconds**.

For example:

```text
1609460000000
```

may be displayed in Excel as:

```text
1.60946E+12
```

This is simply scientific notation and represents the same timestamp.

To convert these timestamps into a readable date and time format, we use `pd.to_datetime()`:

```python
df["Open Time"] = pd.to_datetime(
    df["Open Time"],
    unit="ms"
)
```

The argument:

```python
unit="ms"
```

tells Pandas that the timestamps are measured in **milliseconds**.

After conversion, the data looks like:

```text
Open Time                    Close
----------------------------------------
2021-01-01 00:00:00          28961.66
2021-01-01 00:01:00          29009.91
2021-01-01 00:02:00          28989.30
2021-01-01 00:03:00          28982.69
2021-01-01 00:04:00          28975.65
```

The timestamps show that consecutive observations are separated by one minute. Therefore, this dataset represents a **one-minute time series**.

We can do this using:

```python

```

Now the dataset has the following structure:

```text

Date

2021-01-01 00:01:00    29009.91
2021-01-01 00:02:00    28989.30
2021-01-01 00:03:00    28982.69
```

The date is no longer treated as an ordinary column. Instead, it becomes the **time index** that identifies the chronological position of each observation.

This is useful for:

* preserving the chronological order,
* visualizing the time series,
* checking the sampling frequency,
* splitting the data chronologically,
* resampling the data later if necessary.

# 3. Creating Training and Test Sets

As discussed in the previous section of the tutorial, time-series data should **not normally be randomly shuffled before splitting**.

Instead, we preserve the chronological order.

Suppose the dataset contains:

```text
Time ─────────────────────────────────────────────►

|---------------- Training ----------------|------ Test ------|
              80%                                  20%
```

The training set contains the **earlier observations**, while the test set contains the **later observations**.

This is important because, in a real forecasting scenario, we train the model using the past and evaluate it on the future.

For example, suppose we have 1,000 observations:

```text
Total observations = 1000

Training = first 800 observations
Test     = last 200 observations
```

We can implement this as follows.

```python
train_size = int(len(df) * 0.8)

train_data = df.iloc[:train_size]
test_data = df.iloc[train_size:]
```

Here:

```python
int(len(df) * 0.8)
```

calculates 80% of the observations.

The expression:

```python
df.iloc[:train_size]
```

selects the first 80%, while:

```python
df.iloc[train_size:]
```

selects the remaining 20%.

# 4. Creating a Reusable Visualization Function

Instead of writing plotting code every time we want to visualize the data, we can create a reusable function.

We will use **Matplotlib** to create the visualization.

```python
import matplotlib.pyplot as plt
```

Now we can define the function:

```python
def visualize_train_test(
    train_data,
    test_data,
    last_train_toShow = None,
    top_test_toShow = None,
    title="Training and Test Data",
    xlabel="Date",
    ylabel="Close Price",
    figsize=(14, 6)
):
    """
    Plot training and test time-series data together.
    """

    plt.figure(figsize=figsize)

    if last_train_toShow is not None:
        train_data = train_data[-last_train_toShow:]

    if top_test_toShow is not None:
        train_data = train_data[:top_test_toShow]

    plt.plot(
        train_data.index,
        train_data.values,
        label="Training"
    )

    plt.plot(
        test_data.index,
        test_data.values,
        label="Test"
    )

    plt.title(title)
    plt.xlabel(xlabel)
    plt.ylabel(ylabel)

    plt.legend()
    plt.grid(True)
    plt.tight_layout()

    plt.show()
```

Then:

```python
visualize_train_test(
    train_data["Close"],
    test_data["Close"],
    last_train_toShow = 100,
    top_test_toShow = 100
)
```


# 5. Sliding Window for Time-Series Forecasting

After preparing the Bitcoin dataset and separating it into **training** and **test** sets, the next step is to transform the continuous time series into a format that can be used by time-series forecasting models.

The **sliding window** technique converts a long sequence of observations into multiple **input-target pairs**.

The resulting data will be used by the time-series models introduced in the following lectures, such as **Conv1D, RNN, LSTM, GRU, and other forecasting models**.

Suppose our time series is:

```text
[10, 20, 30, 40, 50, 60, 70, 80]
```

and we choose:

```python
window_size = 3
horizon = 1
```

The first sample is:

```text
Input:   [10, 20, 30]
Target:  [40]
```

Then the window then moves one position:

```text
Input:   [20, 30, 40]
Target:  [50]
```

and so on.

The complete dataset becomes:

```text
[10, 20, 30] → [40]

[20, 30, 40] → [50]

[30, 40, 50] → [60]

[40, 50, 60] → [70]

[50, 60, 70] → [80]
```

Conceptually:

```text
Time ─────────────────────────────────────────────►

       Window          Target
       ┌───────────┐
       │10 20 30   │ → 40
       └───────────┘

          ┌───────────┐
          │20 30 40   │ → 50
          └───────────┘

             ┌───────────┐
             │30 40 50   │ → 60
             └───────────┘

                ┌───────────┐
                │40 50 60   │ → 70
                └───────────┘
```

The window **slides one time step at a time**.

## 5.1 Creating a Reusable Function

We can create a general function that accepts:

```text
data
window_size
horizon
```

and returns:

```text
X
y
```

where:

* `X` contains the input windows,
* `y` contains the corresponding targets.

```python
import numpy as np


def create_sliding_windows(data, window_size, horizon):
    """
    Create input-target pairs using a sliding window.

    Parameters
    ----------
    data : array-like
        One-dimensional time-series data.

    window_size : int
        Number of historical observations
        used as the input.

    horizon : int
        Number of future observations
        used as the target.

    Returns
    -------
    X : numpy.ndarray
        Input windows.

    y : numpy.ndarray
        Target values.
    """

    X = []
    y = []

    # Calculate the number of samples
    num_samples = len(data) - window_size - horizon + 1

    for i in range(num_samples):

        # Input window
        input_window = data[
            i : i + window_size
        ]

        # Target horizon
        target = data[
            i + window_size :
            i + window_size + horizon
        ]

        X.append(input_window)
        y.append(target)

    return np.array(X), np.array(y)
```

In our project, we are using a **single-variable time series** based on Bitcoin's `Close` price.

For a one-step forecasting problem, the structure is:


For example:


```text

Each sample:

Target:
```

## 5.5 Number of Generated Samples

The number of samples generated by the sliding window is:

$[
N-W-H+1
]$

where:

* (N) = number of observations,
* (W) = window size,
* (H) = horizon.

For example:

```python
N = 1000
window_size = 60
horizon = 1
```

Then:

$[
1000-60-1+1=940
]$

Therefore:

```text
X.shape = (940, 60)
y.shape = (940, 1)
```

For 60 observations → 10 predictions we can call the function `create_sliding_windows` as follow

```python
X, y = create_sliding_windows(
    data,
    window_size=60,
    horizon=10
)
```

The function remains unchanged. Only the parameters change.


## 5.6. Important: Train and Test Data

We should create the sliding windows **after** the chronological train/test split:

```text
Original Time Series
        │
        ▼
Chronological Split
        │
        ├───────────────┐
        ▼               ▼
     Training          Test
        │               │
        ▼               ▼
 Sliding Window     Sliding Window
        │               │
        ▼               ▼
 X_train, y_train   X_test, y_test
```

This maintains the chronological nature of the forecasting problem.

We should **not randomly shuffle the original time series before splitting it**.
