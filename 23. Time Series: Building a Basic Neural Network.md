# Building a Basic Neural Network for Time-Series Forecasting with PyTorch

After preparing the Bitcoin closing-price data, splitting it into training and test sets, and creating sliding windows, we can build our first neural-network model for time-series forecasting.

Our sliding-window function produces:

```text
X_train → Input windows
y_train → Target values

X_test  → Input windows
y_test  → Target values
```

For example, suppose:

```python
window_size = 60
horizon = 1
```

Each input sample contains the previous **60 Bitcoin closing prices**, and the target is the **next closing price**:

```text
[Price₁, Price₂, ..., Price₆₀]
                │
                ▼
         Neural Network
                │
                ▼
              Price₆₁
```

In this section, we create a simple **feedforward neural network using PyTorch**.

The model has:

1. One hidden layer with **128 neurons**.
2. A **ReLU activation function** after the hidden layer.
3. One output layer with a **linear output**.
4. Batch size of **128**.
5. **MAE** as the loss function.
6. **100 epochs** for training.


# 1. Model Architecture

The model has the following structure:

```text
       Input Window
   (window_size values)
           │
           ▼
┌─────────────────────────┐
│      Linear Layer       │
│  window_size → 128      │
└─────────────────────────┘
            │
            ▼
          ReLU
            │
            ▼
┌─────────────────────────┐
│      Linear Layer       │
│      128 → horizon      │
└─────────────────────────┘
            │
            ▼
        Prediction
```

Because the layers are executed one after another, we can conveniently define the network using **`nn.Sequential`**.


## 1.1 Creating the Model with `nn.Sequential`

First, import PyTorch:

```python
import torch
import torch.nn as nn
```

Now we define our model:

```python
class TimeSeriesModel(nn.Module):

    def __init__(self, window_size, horizon):
        super().__init__()

        self.layers = nn.Sequential(

            # Hidden layer
            nn.Linear(window_size, 128),

            # ReLU activation function
            nn.ReLU(),

            # Output layer
            nn.Linear(128, horizon)
        )

    def forward(self, x):
        return self.layers(x)
```

### Hidden Layer

The first layer is:

```python
nn.Linear(window_size, 128)
```

This layer receives the historical observations in the sliding window and transforms them into **128 learned features**.

For example, if:

```python
window_size = 60
```

each input sample has:

```text
[Price₁, Price₂, Price₃, ..., Price₆₀]
```

Therefore, the first layer performs:

```text
60 Input Values
       │
       ▼
nn.Linear(60, 128)
       │
       ▼
128 Output Values
```

The value **128** represents the number of neurons in our hidden layer.


### ReLU Activation Function

After the hidden layer, we apply:

```python
nn.ReLU()
```

ReLU stands for **Rectified Linear Unit**.

It introduces nonlinearity into the model.

Without an activation function between the two linear layers, the model would effectively behave like a single linear transformation.

By using ReLU, the model can learn more complex relationships between the historical Bitcoin prices and future prices.



### Output Layer

The final layer is:

```python
nn.Linear(128, horizon)
```

This layer produces the final prediction.

If:

```python
horizon = 1
```

the output is:

```text
128 Features
     │
     ▼
Linear Layer
128 → 1
     │
     ▼
Predicted Next Price
```

For example, if we later use:

```python
horizon = 3
```

the same model architecture can produce three future predictions:

```text
          Input Window
                │
                ▼
          Neural Network
                │
                ▼
[Price(t+1), Price(t+2), Price(t+3)]
```

Notice that the model ends with:

```python
nn.Linear(128, horizon)
```

There is **no activation function after the output layer**. Therefore, the output is linear.

This is appropriate because our problem is a **regression problem**. The Bitcoin closing price is a continuous numerical value, so we do not want to restrict the output to a specific range.


## 1.2 Creating the Model

We can now create an instance of the model:

```python
model = TimeSeriesModel(
    window_size=window_size,
    horizon=horizon
)
```

For example:

```python

```

We can display the model architecture using:


The output will be similar to:

```text
TimeSeriesModel(
  (layers): Sequential(

    (1): ReLU()
    (2): Linear(in_features=128, out_features=1, bias=True)

```

## 1.3 Defining the Loss Function

Our forecasting model uses **Mean Absolute Error (MAE)** as the loss function.

In PyTorch, MAE is implemented using:

```python
criterion = nn.L1Loss()
```

The loss function measures the average absolute difference between the predicted and actual values.

For example:

```text
Actual Price:      100,000
Predicted Price:    99,500
                    ───────
Absolute Error:        500
```

During training, the model attempts to minimize this error.

Therefore, we define:

```python
criterion = nn.L1Loss()
```

## 1.4 Defining the Optimizer

We need an optimizer to update the model parameters during training.

Here, we use the Adam optimizer:

```python
optimizer = torch.optim.Adam(
    model.parameters()
)
```

# 2. Creating the Dataset and DataLoader

We use a `DataLoader` to divide the dataset into batches.

First, import:

```python
from torch.utils.data import TensorDataset, DataLoader
```

Then create the training and test datasets:

```python
def create_data_loaders(
    X_train,
    y_train,
    X_test,
    y_test,
    batch_size=128
):
    """
    Create PyTorch DataLoaders for
    training and test datasets.
    """

    # Create TensorDatasets
    train_dataset = TensorDataset(
        X_train,
        y_train
    )

    test_dataset = TensorDataset(
        X_test,
        y_test
    )

    # Create DataLoaders
    train_loader = DataLoader(
        train_dataset,
        batch_size=batch_size,
        shuffle=False
    )

    test_loader = DataLoader(
        test_dataset,
        batch_size=batch_size,
        shuffle=False
    )

    return train_loader, test_loader
```

we can create the DataLoaders with:

```python
train_loader, test_loader = create_data_loaders(
    X_train_tensor,
    y_train_tensor,
    X_test_tensor,
    y_test_tensor,
    batch_size=128
)
```

We can check the first batch:

```python
X_batch, y_batch = next(iter(train_loader))

print("Input shape:", X_batch.shape)
print("Target shape:", y_batch.shape)
```

For example, if:

```python
window_size = 60
horizon = 1
batch_size = 128
```

the output will be approximately:

```
Input shape: torch.Size([128, 60])
Target shape: torch.Size([128, 1])
```

This means:

We use:

# 3. Training the Model

First, define the device:

```python
device = torch.device(
    "cuda" if torch.cuda.is_available() else "cpu"
)

print("Using device:", device)
```

Then define the training function:

```python
def train_model(
    model,
    train_loader,
    test_loader,
    criterion,
    optimizer,
    epochs=100
):

    # Move model to device
    model = model.to(device)

    # Store training history
    train_losses = []
    test_losses = []


    for epoch in range(epochs):

        # -----------------------
        # Training phase
        # -----------------------
        model.train()

        running_loss = 0.0


        for inputs, targets in train_loader:

            # Move data to device
            inputs = inputs.to(device)
            targets = targets.to(device)

            # Clear previous gradients
            optimizer.zero_grad()

            # Forward pass
            predictions = model(inputs)

            # Compute MAE loss
            loss = criterion(
                predictions,
                targets
            )

            # Backpropagation
            loss.backward()

            # Update model parameters
            optimizer.step()

            # Store batch loss
            running_loss += loss.item()


        # Average training loss
        epoch_train_loss = (
            running_loss / len(train_loader)
        )


        # -----------------------
        # Evaluation phase
        # -----------------------
        model.eval()

        running_test_loss = 0.0


        # Disable gradient calculation
        with torch.no_grad():

            for inputs, targets in test_loader:

                # Move data to device
                inputs = inputs.to(device)
                targets = targets.to(device)

                # Forward pass
                predictions = model(inputs)

                # Compute MAE loss
                loss = criterion(
                    predictions,
                    targets
                )

                # Store batch loss
                running_test_loss += loss.item()


        # Average test loss
        epoch_test_loss = (
            running_test_loss / len(test_loader)
        )


        # -----------------------
        # Store history
        # -----------------------
        train_losses.append(
            epoch_train_loss
        )

        test_losses.append(
            epoch_test_loss
        )


        # Print results
        print(
            f"Epoch [{epoch + 1}/{epochs}] "
            f"Train MAE: {epoch_train_loss:.4f} "
            f"Test MAE: {epoch_test_loss:.4f}"
        )


    return train_losses, test_losses
```

### Calling the Training Function

Before calling the function, define the loss function and optimizer.

```python

# Optimizer: Adam
optimizer = torch.optim.Adam(
    model.parameters(),
    lr=0.001
)
```

Now train the model:

