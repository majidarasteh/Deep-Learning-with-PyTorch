Saving the **model `state_dict`** is the standard PyTorch approach is rather than the entire model object. Since we have three different models with different architectures/configurations, it is useful to save and reload them explicitly.

## 1. Save the three models

After you have finished training `model18` and `model18_ft`, save their parameters:

```python
# Save the pretrained ResNet50 model
torch.save(
    model50.state_dict(),
    "model50_direct_use.pth"
)

# Save the feature extraction model
torch.save(
    model18.state_dict(),
    "model18_feature_extraction.pth"
)

# Save the fine-tuned model
torch.save(
    model18_ft.state_dict(),
    "model18_fine_tuning.pth"
)
```

You will now have:

```text
model50_direct_use.pth
model18_feature_extraction.pth
model18_fine_tuning.pth
```

### Important point

For `model18` and `model18_ft`, we are saving the **trained parameters**, not the model architecture itself.

Therefore, when we reload them, we must first recreate the correct architecture and then load the saved parameters.


## 2. Reload `model50`

`model50` is the direct-use ImageNet model.

First recreate the architecture with the same pretrained weights:

```python
weights50 = ResNet50_Weights.DEFAULT
model50_loaded = resnet50(weights=weights50)
```

Then load the saved parameters:

```python
model50_loaded.load_state_dict(
    torch.load(
        "model50_direct_use.pth",
        map_location=device
    )
)
```

Move it to the appropriate device:

```python
model50_loaded = model50_loaded.to(device)
```

Finally, put it into evaluation mode:

```python
model50_loaded.eval()
```

So the complete code is:

```python
weights50 = ResNet50_Weights.DEFAULT

model50_loaded = resnet50(weights=weights50)

model50_loaded.load_state_dict(
    torch.load(
        "model50_direct_use.pth",
        map_location=device
    )
)

model50_loaded = model50_loaded.to(device)
model50_loaded.eval()
```

Now `model50_loaded` is ready for prediction.


## 3. Reload `model18` — Feature Extraction

This one is slightly different.

Remember that during feature extraction we changed the final layer:

```python
model18.fc = nn.Linear(num_features, 1)
```

Therefore, when reloading the model, we must recreate this modified architecture first.

```python
weights18 = ResNet18_Weights.DEFAULT
model18_loaded = resnet18(weights=weights18)
num_features = model18_loaded.fc.in_features

model18_loaded.fc = nn.Linear(
    num_features,
    1
)
```

Now load the saved parameters:

```python
model18_loaded.load_state_dict(
    torch.load(
        "model18_feature_extraction.pth",
        map_location=device
    )
)
```

Move to the device and evaluation mode:

```python
model18_loaded = model18_loaded.to(device)
model18_loaded.eval()
```

The complete code is:

```python
weights18 = ResNet18_Weights.DEFAULT

model18_loaded = resnet18(weights=weights18)

num_features = model18_loaded.fc.in_features

model18_loaded.fc = nn.Linear(
    num_features,
    1
)

model18_loaded.load_state_dict(
    torch.load(
        "model18_feature_extraction.pth",
        map_location=device
    )
)

model18_loaded = model18_loaded.to(device)

model18_loaded.eval()
```


## 4. Reload `model18_ft` — Fine-Tuning

This model needs one additional step.

When we created the fine-tuned model, we:

1. Loaded pretrained ResNet18.
2. Froze all parameters.
3. Unfroze `layer4`.
4. Replaced `fc`.

Therefore, we should recreate the same architecture.

```python
weights18 = ResNet18_Weights.DEFAULT

model18_ft_loaded = resnet18(weights=weights18)
```

Freeze everything:

```python
for param in model18_ft_loaded.parameters():
    param.requires_grad = False
```

Unfreeze `layer4`:

```python
for param in model18_ft_loaded.layer4.parameters():
    param.requires_grad = True
```

Replace the classifier:

```python
num_features = model18_ft_loaded.fc.in_features

model18_ft_loaded.fc = nn.Linear(
    num_features,
    1
)
```

Now load the saved parameters:

```python
model18_ft_loaded.load_state_dict(
    torch.load(
        "model18_fine_tuning.pth",
        map_location=device
    )
)
```

Finally:

```python
model18_ft_loaded = model18_ft_loaded.to(device)

model18_ft_loaded.eval()
```

Complete version:

```python
weights18 = ResNet18_Weights.DEFAULT

model18_ft_loaded = resnet18(weights=weights18)

# Freeze all parameters
for param in model18_ft_loaded.parameters():
    param.requires_grad = False

# Unfreeze layer4
for param in model18_ft_loaded.layer4.parameters():
    param.requires_grad = True

# Replace the classifier
num_features = model18_ft_loaded.fc.in_features

model18_ft_loaded.fc = nn.Linear(
    num_features,
    1
)

# Load saved parameters
model18_ft_loaded.load_state_dict(
    torch.load(
        "model18_fine_tuning.pth",
        map_location=device
    )
)

model18_ft_loaded = model18_ft_loaded.to(device)

model18_ft_loaded.eval()
```

## 5. Test the Reloaded Models

For `model50_loaded`, we can use our original prediction function:

```python
predicted_class, probability = predict_image(
    model=model50_loaded,
    image_path=image_path,
    weights=weights50,
    device=device
)

print(
    f"Prediction: {predicted_class} "
    f"(probability={probability:.4f})"
)
```

For the two binary classifiers, use our `predict_image_FE()` function:

```python
predicted_class, probability = predict_image_FE(

print(
    f"Prediction: {predicted_class} "
```

## 6. A Useful Comparison

Your three saved models represent three different transfer-learning strategies:

```text
                    Transfer Learning
                           │
          ┌────────────────┼────────────────┐
          │                │                │
      model50           model18        model18_ft
     Direct Use      Feature Extraction   Fine-Tuning
          │                │                │
     ImageNet        ResNet18 + FC      ResNet18 + FC
     1000 classes      Cat/Dog           Cat/Dog
          │                │                │
      No training      FC trained      Layer4 + FC trained
```
