# Feature Extraction with PyTorch

## 1. Introduction

Feature extraction is one of the main approaches to transfer learning.

In feature extraction, we use a model that has already been trained on a large dataset such as ImageNet. The pretrained model has already learned useful visual features such as:

* edges
* textures
* shapes
* object parts
* complex visual patterns

Instead of training the entire model from scratch, we keep the pretrained part of the model fixed and train a new classifier for our target task.

In this tutorial, we use a pretrained **ResNet18** model to classify images into two classes:

```text
Cat → 0
Dog → 1
```

The general idea is:

```text
Input Image
     ↓
Pretrained ResNet18
     ↓
Frozen Feature Extractor
     ↓
New Classification Layer
     ↓
Cat / Dog
```

The important point is:

> **In feature extraction, the pretrained layers are frozen and only the newly added classifier is trained.**

## 6. Get the Preprocessing Transformations

The input images need to be processed in the same way expected by the pretrained ResNet18 weights.

We obtain the appropriate preprocessing pipeline using:

```python
# Get the preprocessing transformations
preprocess18 = weights18.transforms()
print(preprocess18)
```

This preprocessing pipeline performs the transformations required by the pretrained weights, such as resizing, cropping when appropriate, conversion to tensors, scaling, and normalization.

Using `weights18.transforms()` is preferable to manually specifying these values because the preprocessing is directly associated with the selected pretrained weights.


## 7. Create Training and Test Transformations

For training data, we can use data augmentation to create slightly different versions of training images.

For example:

```python
transforms.RandomHorizontalFlip()
```

randomly flips some images horizontally.

We can also use:

```python
transforms.TrivialAugmentWide()
```

to apply random augmentation.

For test data, however, we should not use random augmentation. The test images should be processed consistently.

We therefore create a reusable function:

```python
def create_transform(weights):

    preprocess = weights.transforms()

    # We can add data augmentation for training data
    train_transform = transforms.Compose([
        transforms.RandomHorizontalFlip(p=0.5),
        transforms.TrivialAugmentWide(num_magnitude_bins=40),
        preprocess
    ])

    # We do not add data augmentation for test data
    test_transform = weights.transforms()

    return train_transform, test_transform
```

## 8. Create Training and Test Datasets

```python
def create_datasets(train_dir, test_dir, weights):
```


For testing, we use:


because there is no need to randomly reorder the test data.


## 10. Freeze All Pretrained Parameters

This is the most important step in feature extraction.

We want to use ResNet18 as a **fixed feature extractor**.

Therefore, we freeze all of its pretrained parameters:

```python
# Freeze all pretrained parameters
for param in model18.parameters():
    param.requires_grad = False
```

Now the pretrained ResNet18 layers will not be updated during training.

Conceptually:

```text
Pretrained ResNet18
       ↓
   FROZEN
       ↓
Visual Features
```

## 11. Replace the Final Classification Layer

The original ResNet18 was designed for 1000-class ImageNet classification.

We need to replace its final classification layer with a classifier for our binary Cat/Dog problem.

First, we obtain the number of input features of the original `fc` layer:

```python
num_features = model18.fc.in_features
print(num_features)
```

For ResNet18, this is:

```text
512
```

We then replace the original classifier:

```python
model18.fc = nn.Linear(
    num_features,
    1
)
```

The model now has the following structure:

```text
Input Image
     ↓
ResNet18
     ↓
512 Features
     ↓
Linear(512, 1)
     ↓
One Output
```

Why do we use **one output**?

Because this is a binary classification problem:

```text
0 → Cat
1 → Dog
```

The output will be a **logit**, which we later convert to a probability using the sigmoid function.

The new classification layer was created after the original model was moved to the device.

To **make sure the complete model is on the correct device**, we can call:

```python
model18 = model18.to(device)
```

## 12. Check Trainable Parameters

We can check which parameters will actually be updated during training.

```python
for name, param in model18.named_parameters():

    if param.requires_grad:
        print(name)
```

The expected output is:

```text
fc.weight
fc.bias
```

This confirms that the pretrained ResNet18 parameters are frozen and only the new classification layer is trainable.

This is the key difference between feature extraction and fine-tuning.

## 13. Define the Loss Function

This is a **binary classification** problem.

We therefore use:

```python
criterion = nn.BCEWithLogitsLoss()
```

`BCEWithLogitsLoss` combines the sigmoid operation and binary cross-entropy loss.

Therefore, we **do not add a sigmoid layer to the model**.

The model produces:

```text
Raw Logit
```

and `BCEWithLogitsLoss` internally handles the sigmoid calculation.


## 14. Define the Optimizer

Since only the new classification layer is trainable, we only need to optimize:

```python
model18.fc.parameters()
```

Therefore:

```python
optimizer = torch.optim.Adam(
    model18.fc.parameters(),
    lr=0.001
)
```

This is an important feature-extraction detail.

We are **not** optimizing all ResNet18 parameters.

Only:

```text
fc.weight
fc.bias
```

are updated.


## 15. Define the Accuracy Function

We need an accuracy function for binary classification.

The model produces logits, so we first convert them into probabilities using sigmoid.

```python
def accuracy_fn(y_true, y_pred):
    probabilities = torch.sigmoid(y_pred)
    predictions = (probabilities > 0.5).float()
    correct = (predictions == y_true).float().sum()
    accuracy = correct / len(y_true)
    return accuracy * 100
```

The prediction rule is:

```text
Probability < 0.5  → Cat
Probability ≥ 0.5 → Dog
```

## 16. Training Function

Now we create the main training function.

The function performs both:

* training
* evaluation

for every epoch.

```python
def train_model(
    model, 
    train_loader, 
    test_loader,
    optimizer,
    criterion = nn.BCEWithLogitsLoss(),
    epochs=10, 
    learning_rate = 0.001
):
    train_losses, test_losses, train_accuracies, test_accuracies = [], [], [], []

    for epoch in range(epochs):
        model.train()
        epoch_train_loss, epoch_train_acc = 0., 0.

        # ---- TRAINING LOOP ----
        for batch_features, batch_targets in train_loader:
            # shape: [batch_size, 1]
            batch_features, batch_targets = batch_features.to(device), batch_targets.unsqueeze(1).float().to(device)

            # 1.
            optimizer.zero_grad()

            # 2. Prediction (Forward pass)
            batch_predictions = model(batch_features)

            # 3. Compute loss and accuracy
            batch_loss = criterion(batch_predictions, batch_targets)
            batch_acc = accuracy_fn(batch_targets, batch_predictions)

            batch_loss.backward()
            optimizer.step()

            epoch_train_loss += batch_loss.item()
            epoch_train_acc += batch_acc

        # Average over all batches
        epoch_train_loss /= len(train_loader)
        epoch_train_acc /= len(train_loader)

        # ---- EVALUATION LOOP ----
        model.eval()
        epoch_test_loss, epoch_test_acc = 0., 0.
        with torch.no_grad():
            for batch_features, batch_targets in test_loader:
                # shape: [batch_size, 1]
                batch_features, batch_targets = batch_features.to(device), batch_targets.unsqueeze(1).float().to(device)
                
                batch_predictions = model(batch_features)
                batch_loss = criterion(batch_predictions, batch_targets)
                batch_acc = accuracy_fn(batch_targets, batch_predictions)

                epoch_test_loss += batch_loss.item()
                epoch_test_acc += batch_acc

        epoch_test_loss /= len(test_loader)
        epoch_test_acc /= len(test_loader)

        # Store results
        train_losses.append(epoch_train_loss)
        test_losses.append(epoch_test_loss)
        train_accuracies.append(epoch_train_acc)
        test_accuracies.append(epoch_test_acc)

        # Print all epochs
        if epoch % 1 == 0:
            print(f"Epoch [{epoch}/{epochs}] | "
                  f"Train Loss: {epoch_train_loss:.4f} | Train Acc: {epoch_train_acc:.2f}% | "
                  f"Test Loss: {epoch_test_loss:.4f} | Test Acc: {epoch_test_acc:.2f}%")

    return train_losses, test_losses, train_accuracies, test_accuracies
```

## 17. Train the Feature Extraction Model

Now we can train the model.

```python
train_losses_FE, test_losses_FE, train_accuracies_FE, test_accuracies_FE = train_model(
    model=model18,
    train_loader=train_dataloader,
    test_loader=test_dataloader,
    optimizer=optimizer,
    criterion=criterion,
    epochs=10
)
```

Notice what happens during training:

```text
ResNet18 parameters
        ↓
      Frozen
        ↓
    No updates
```

while:

```text
 New fc layer
      ↓
   Trainable
      ↓
Updated by Adam
```

Therefore, the training process is much lighter than training the entire ResNet18 from scratch.

## 19. Predict a Single Image

After training, we can use the model to classify a new image.

We use the **same preprocessing associated with the pretrained ResNet18 weights**.

```python
def predict_image_FE(
    model,
    image_path,
    weights,
    device
):

    # Get preprocessing transformations
    preprocess = weights.transforms()

    # Load image
    image = Image.open(image_path).convert("RGB")

    # Apply preprocessing
    input_tensor = preprocess(image)

    # Add batch dimension
    input_batch = input_tensor.unsqueeze(0)

    # Move input to device
    input_batch = input_batch.to(device)

    # Evaluation mode
    model.eval()

    with torch.no_grad():

        # Forward pass
        output = model(input_batch)

        # Convert logit to probability
        probability = torch.sigmoid(output).item()

    # Convert probability to class
    if probability >= 0.5:
        predicted_class = "Dog"
    else:
        predicted_class = "Cat"

    return predicted_class, probability
```


Call the prediction function:

```text

                        ▼
              Freeze all parameters
                        │
                        ▼

                        ▼
              Add Linear(512, 1)

                        │
                        ▼
                    Cat / Dog
```


## 20. Feature Extraction vs. Direct Use

It is important to distinguish feature extraction from the previous **Direct Use** approach.

| Approach           | Pretrained model          | New classifier | Training |
| ------------------ | ------------------------- | -------------- | -------- |
| Direct use         | Used as it is             | No             | No       |
| Feature extraction | Frozen                    | Yes            | Yes      |
| Fine-tuning        | Partially/fully trainable | Yes            | Yes      |

### Direct Use

The pretrained model is used without changing its architecture:

```text
Pretrained ResNet
       ↓
ImageNet prediction
```

No training is performed.

### Feature Extraction

The pretrained layers are frozen and a new classifier is trained:

```text
Pretrained ResNet
       ↓
Frozen features
       ↓
New classifier
       ↓
Cat / Dog
```

> **Feature extraction reuses the representations learned by a pretrained model while keeping the pretrained parameters frozen and training only a new classifier for the target task.**

### Fine-Tuning

The pretrained layers are allowed to learn further:

```text
Pretrained ResNet
       ↓
Some/all layers trainable
       ↓
New classifier
       ↓
Cat / Dog
```
