
# 1. Loading the Dataset

Before building a text classification model, we must first load the dataset into our Python environment. In this tutorial, we use the **SMS Spam Collection** dataset, which contains SMS messages labeled as either **ham** (legitimate message) or **spam** (unsolicited advertisement or scam).

Each row in the dataset contains two fields:

* **label** – the class of the message (`ham` or `spam`)
* **text** – the SMS message itself

Although the file has a `.csv` extension, it is actually **tab-separated**. Therefore, we must specify the tab character (`\t`) as the delimiter when reading the file. Since the dataset does not include a header row, we also provide the column names manually.

The following code loads the dataset using the **Pandas** library.

```python
import pandas as pd

# Load the SMS Spam Collection dataset
df = pd.read_csv(
    "spam_ham.csv",
    sep="\t",
    header=None,
    names=["label", "text"]
)

# Display the first five samples
df.head()
```

### Explanation

* `import pandas as pd` imports the Pandas library using the conventional alias `pd`.
* `sep="\t"` specifies that the values in the file are separated by **tab characters** rather than commas.
* `header=None` tells Pandas that the first row contains data, not column names.
* `names=["label", "text"]` assigns meaningful names to the two columns.
* `df.head()` displays the first five rows, allowing us to verify that the dataset has been loaded correctly.

If the dataset is loaded successfully, the output will look similar to the following:

Yes, that's a good point to mention in the tutorial. In many real-world datasets, the samples may be **ordered by class** (for example, all ham messages followed by all spam messages). Training a model on such an ordered dataset can introduce bias, especially when the data is later split into training and validation sets. Therefore, it is good practice to **randomly shuffle the dataset** immediately after loading it.

# Shuffling the Dataset

Before proceeding with data exploration and preprocessing, it is a good practice to randomly shuffle the dataset. In some datasets, the samples may be grouped by their labels—for example, all **ham** messages followed by all **spam** messages. If the dataset is not shuffled, the training and validation sets may not contain a representative distribution of both classes, which can negatively affect the model's ability to learn and generalize.

Pandas provides the `sample()` function to randomly reorder the rows of a DataFrame. Setting `frac=1` returns all rows in a random order, while `random_state` ensures that the shuffle is reproducible.

```python
# Shuffle the dataset
df = df.sample(frac=1, random_state=42).reset_index(drop=True)

# Display the first five rows after shuffling
df.head()
```

### Explanation

* `frac=1` tells Pandas to return **100% of the rows** in a random order.
* `random_state=42` sets a fixed random seed so that the same shuffled order is produced each time the code is executed, ensuring reproducible experiments.
* `reset_index(drop=True)` creates a new sequential index (0, 1, 2, ...) after shuffling and discards the original row indices.

After shuffling, the dataset contains exactly the same samples, but their order is randomized. This helps ensure that subsequent steps, such as splitting the dataset into training and validation sets, produce representative subsets with a more balanced distribution of spam and ham messages.

# Create Train and Test dataset

The next step is to split the dataset into **training** and **testing** sets. The training set is used to learn the model parameters, while the testing set is kept completely unseen during training and is used to evaluate how well the trained model generalizes to new data.

A common choice is to use **80% of the data for training** and **20% for testing**. To ensure that both sets preserve approximately the same proportion of **ham** and **spam** messages, we perform a **stratified split**. This is especially important because the SMS Spam Collection dataset is imbalanced.

First, import the `train_test_split` function from Scikit-learn.

```python
from sklearn.model_selection import train_test_split
```

Then split the dataset as follows.

```python
# Split the dataset into training and testing sets
train_df, test_df = train_test_split(
    df,
    test_size=0.2,
    stratify=df["label"],
    random_state=42
)

# Reset row indices
train_df = train_df.reset_index(drop=True)
test_df = test_df.reset_index(drop=True)

print(f"Training samples: {len(train_df)}")
print(f"Testing samples : {len(test_df)}")
```

### Explanation

* `test_size=0.2` allocates **20%** of the dataset to the test set and **80%** to the training set.
* `stratify=df["label"]` ensures that the proportions of **ham** and **spam** messages remain approximately the same in both subsets.
* `random_state=42` fixes the random seed so that the same split is produced every time the code is executed, making experiments reproducible.
* `reset_index(drop=True)` creates new sequential indices for both DataFrames after splitting.

For the SMS Spam Collection dataset, the output will be approximately:

```text
Training samples: 4457
Testing samples : 1115
```

At this point, we have two independent datasets:

* **`train_df`**: used to train the text classification model.
* **`test_df`**: used only after training to evaluate the model's performance on unseen messages.
