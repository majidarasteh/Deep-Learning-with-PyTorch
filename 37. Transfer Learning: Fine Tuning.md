# Fine-Tuning with PyTorch

## 1. What is Fine-Tuning?

In **feature extraction**, we use a pretrained model as a fixed feature extractor:

* All pretrained layers are frozen.
* Only the newly added classifier is trained.
  
In **fine-tuning**, we go one step further:

> We allow some of the pretrained layers to be updated using our new dataset.

The idea is that the pretrained model has already learned useful visual features from a large dataset such as ImageNet.

For example, early layers of ResNet18 learn general features such as:

* edges
* colors
* textures
* simple shapes

Later layers learn more task-specific features.

Therefore, we usually keep the early layers frozen and fine-tune only the **last few layers**.

### Feature Extraction

```text
Image
  ↓
Frozen layers
  ↓
Frozen layers
  ↓
Frozen layers
  ↓
New classifier ← TRAIN
```

### Fine-Tuning

```text
Image
  ↓
Frozen layers
  ↓
Frozen layers
  ↓
Fine-tuned layers ← TRAIN
  ↓
Fine-tuned layers ← TRAIN
  ↓
New classifier ← TRAIN
```

> **This is particularly useful when our dataset is different from the original ImageNet dataset.**

## 2. Why Not Fine-Tune the Entire Model?

ResNet18 contains many parameters.

If we train the entire network:

```text
All layers → trainable
```

then:

* training requires more GPU/CPU computation
* more memory is required
* training takes longer
* there is a greater risk of overfitting when the dataset is small

Since our **Cats and Dogs** dataset is relatively small and your computer has computational limitations, we will use a lightweight approach:

> **Freeze most of ResNet18 and fine-tune only the final residual block and the classifier.**

This gives us a good practical demonstration of fine-tuning without requiring a powerful GPU.

We will freeze:

```text
Conv1
Layer 1
Layer 2
Layer 3
```

and fine-tune:

```text
Layer 4
FC
```

So only a relatively small part of the network will be trained.


## 3. Load the Pretrained ResNet18

We start exactly as we did for feature extraction.

```python
# Load pretrained ResNet18 weights
weights18 = ResNet18_Weights.DEFAULT

# Load the pretrained ResNet18 model
model18_ft = resnet18(weights=weights18)

# Move model to device
model18_ft = model18_ft.to(device)
```

## 4. Freeze All Pretrained Layers and Unfreeze the Final ResNet Block

First, we freeze the entire pretrained model.

```python
# Freeze all pretrained parameters
for param in model18_ft.parameters():
    param.requires_grad = False
```

At this point:

```text
All ResNet18 parameters
        ↓
requires_grad = False
```

Therefore, none of the pretrained layers will be updated during backpropagation.

Now we want to fine-tune only the final convolutional block.

In ResNet18, this block is called:

```python
layer4
```

We can make its parameters trainable:

```python
# Unfreeze the final ResNet block
for param in model18_ft.layer4.parameters():
    param.requires_grad = True
```

Now the situation is:

```text
Conv1       → Frozen
Layer 1     → Frozen
Layer 2     → Frozen
Layer 3     → Frozen
Layer 4     → Trainable
FC          → Trainable
```

This is the key difference between **feature extraction** and **fine-tuning**.


## 5. Replace the Final Classifier

Our pretrained ResNet18 was originally designed for ImageNet, which has 1000 classes.

We only have two classes:

```text
cats
dogs
```

Therefore, we replace the final fully connected layer.

First, find the number of input features:

```python
num_features = model18_ft.fc.in_features
```

For ResNet18, this is 512.

Now replace the classifier:

```python
model18_ft.fc = nn.Linear(num_features, 1)
```

Because we are doing binary classification, the new classifier produces **one logit**.

The architecture now becomes:

```text
ResNet18
   ↓
Layer 4 ← Fine-tuned
   ↓
FC ← New and trainable
   ↓
1 logit
```

## 6. Check Which Layers Are Trainable

It is useful to verify that we have not accidentally made the whole model trainable.

```python
for name, param in model18_ft.named_parameters():
    if param.requires_grad:
        print(name)
```

You should see parameters belonging mainly to:

```text
layer4
fc
```

For example:

```text
layer4.0.conv1.weight
layer4.0.conv1.bias
...
layer4.1.conv2.weight
layer4.1.conv2.bias
...
fc.weight
fc.bias
```

This confirms that only the final part of the network will be updated.

## 7. Why Do We Unfreeze the Last Layer?

The final layers of a pretrained network contain more **task-specific representations**.

For example, ImageNet contains many classes such as:

```text
dog
cat
bird
car
truck
...
```

The pretrained ResNet18 has already learned useful visual representations.

However, our task is specifically:

```text
Cat vs Dog
```

Therefore, allowing the final block to adapt can help the network learn features that are more useful for distinguishing cats from dogs.

We don't need to relearn basic visual concepts such as edges and textures.


## 8. Use a Small Learning Rate

This is particularly important for fine-tuning.

In feature extraction, our new classifier starts with random weights, so we can use a relatively larger learning rate.

For fine-tuning, pretrained weights already contain useful information.

We don't want to make large changes to them.

Therefore, we use a **small learning rate**.

For example:

```python
optimizer = optim.Adam(
    filter(lambda p: p.requires_grad, model18_ft.parameters()),
    lr=0.0001
)
```

The important part is:

```python
filter(lambda p: p.requires_grad, model18_ft.parameters())
```

This means:

> Give the optimizer only the parameters that are trainable.

Therefore, frozen parameters are not updated.


## 9. Loss Function

We are still performing binary classification.

Our model produces one logit:

```text
output = logit
```

Therefore, we use:

```python
criterion = nn.BCEWithLogitsLoss()
```

This combines:

```text
Sigmoid
+
Binary Cross Entropy
```

into one numerically stable operation.

So our setup is:

```python
criterion = nn.BCEWithLogitsLoss()
```

## 10. Complete Fine-Tuning Setup

Putting the previous steps together:

```python
# Load pretrained ResNet18
weights18 = ResNet18_Weights.DEFAULT

model18_ft = resnet18(weights=weights18)

# Freeze all pretrained parameters
for param in model18_ft.parameters():
    param.requires_grad = False

# Unfreeze the final ResNet block
for param in model18_ft.layer4.parameters():
    param.requires_grad = True

# Replace the final classifier
num_features = model18_ft.fc.in_features
model18_ft.fc = nn.Linear(num_features, 1)

# Move model to device
model18_ft = model18_ft.to(device)

# Loss function
criterion = nn.BCEWithLogitsLoss()

# Optimizer
optimizer_ft = optim.Adam(
    filter(lambda p: p.requires_grad, model18_ft.parameters()),
    lr=0.0001
)
```

## 11. Check the Number of Trainable Parameters

It is useful to compare the total number of parameters with the number of parameters that we actually train.

```python
total_params = sum(
    p.numel() for p in model18_ft.parameters()
)

trainable_params = sum(
    p.numel() for p in model18_ft.parameters()
    if p.requires_grad
)

print(f"Total parameters: {total_params:,}")
print(f"Trainable parameters: {trainable_params:,}")
```

You should notice that:

```text
Trainable parameters << Total parameters
```

This is exactly what we want.

We are using the majority of ResNet18 as a fixed pretrained feature extractor while adapting only the final part.

## 15. Feature Extraction vs Fine-Tuning

This distinction is extremely important.

| Approach           | Pretrained layers                         | New classifier | Computational cost |
| ------------------ | ----------------------------------------- | -------------- | ------------------ |
| Direct Use         | Frozen/not trained                        | Not replaced   | Very low           |
| Feature Extraction | Frozen                                    | Train          | Low                |
| Fine-Tuning        | Mostly frozen, some train                 | Train          | Medium             |
| Full Training      | No pretrained weights or all layers train | Train          | High               |

For our experiment:

### Feature Extraction

```text
ResNet18
│
├── Layer 1 ── Frozen
├── Layer 2 ── Frozen
├── Layer 3 ── Frozen
├── Layer 4 ── Frozen
└── FC ─────── Train
```

### Our Fine-Tuning

```text
ResNet18
│
├── Layer 1 ── Frozen
├── Layer 2 ── Frozen
├── Layer 3 ── Frozen
├── Layer 4 ── Train
└── FC ─────── Train
```

### Full Fine-Tuning

```text
ResNet18
│
├── Layer 1 ── Train
├── Layer 2 ── Train
├── Layer 3 ── Train
├── Layer 4 ── Train
└── FC ─────── Train
```
