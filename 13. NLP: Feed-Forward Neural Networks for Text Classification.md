# 1. Feed-Forward Neural Network for Text Classification

In the previous sections, we loaded the SMS Spam Collection dataset, split it into training and test sets, tokenized the text, and transformed each word into a dense vector using an embedding layer. At this stage, every SMS message is represented as a sequence of word embeddings and is ready to be processed by a neural network.

In this section, we will implement our first text classification model using a **Feed-Forward Neural Network (FFNN)**. Although this architecture does not explicitly model the sequential nature of language, it provides a simple and effective baseline for understanding the complete text classification pipeline. In the following chapters, we will replace this baseline with more advanced architectures such as **RNNs**, **LSTMs**, **GRUs**, and **CNNs for text classification**, allowing us to compare their performance on the same dataset.

The overall workflow is illustrated below.

```text
SMS Message
      ↓
Tokenization
      ↓
Token IDs
      ↓
Embedding Layer
      ↓
Average Pooling
      ↓
Feed-Forward Neural Network
      ↓
Spam / Ham Prediction
```


## 1.1 Building the Model

After the embedding layer, each SMS message is represented as a matrix of shape

```text
(sequence_length, embedding_dimension)
```

For example,

```text
(30, 128)
```

where each row corresponds to the embedding vector of one word.

A feed-forward neural network, however, expects a **single feature vector** for each input sample rather than a sequence of vectors. Therefore, before passing the data to the classifier, we compute the average of all word embeddings.

This operation is known as **average pooling** and produces a fixed-length representation of the entire sentence.

The classifier itself consists of two fully connected layers separated by a ReLU activation function. The final Sigmoid activation produces a probability between **0** and **1**, representing the likelihood that the SMS message is spam.

The complete implementation is shown below.

```python
import torch
import torch.nn as nn

class FeedForwardClassifier(nn.Module):

    def __init__(self, vocab_size, embedding_dim, hidden_dim):

        super().__init__()

        # Word embedding layer
        self.embedding = nn.Embedding(
            num_embeddings=vocab_size,
            embedding_dim=embedding_dim,
            padding_idx=0
        )

        # Feed-forward classifier
        self.classifier = nn.Sequential(
            nn.Linear(embedding_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, 1),
            nn.Sigmoid()
        )

    def forward(self, x):

        # Convert token IDs to word embeddings
        x = self.embedding(x)

        # Average the embeddings across the sequence dimension
        x = x.mean(dim=1)

        # Classification
        x = self.classifier(x)

        return x
```

Next, we create an instance of the model.

```python
vocab_size = len(vocab)
embedding_dim = 128
hidden_dim = 64

model_FFNN = FeedForwardClassifier(
    vocab_size=vocab_size,
    embedding_dim=embedding_dim,
    hidden_dim=hidden_dim
)

print(model_FFNN)
```


## 1.2 Understanding the Model Architecture

Suppose a mini-batch contains **32** SMS messages, each padded to **30** tokens.

The dimensions of the data change as follows.

| Layer           | Output Shape    |
| --------------- | --------------- |
| Input           | `(32, 30)`      |
| Embedding       | `(32, 30, 128)` |
| Average Pooling | `(32, 128)`     |
| Linear          | `(32, 64)`      |
| ReLU            | `(32, 64)`      |
| Linear          | `(32, 1)`       |
| Sigmoid         | `(32, 1)`       |

The final output is a probability indicating how likely each SMS message is to belong to the **spam** class.


## 1.3 Defining the Loss Function and Optimizer

Training a neural network requires two essential components:

1. **A loss function**, which measures the difference between the predicted probabilities and the true labels.
2. **An optimizer**, which updates the model parameters to minimize the loss.

Since SMS spam detection is a binary classification problem, we use the **Binary Cross-Entropy Loss** together with the **Adam** optimizer.

```python
import torch.optim as optim

criterion = nn.BCELoss()

optimizer = optim.Adam(
    model_FFNN.parameters(),
    lr=0.001
)
```

The loss function guides the learning process, while the optimizer determines how the model parameters are updated after each training step.

```python
from torch.utils.data import Dataset

    def __len__(self):
        return len(self.texts)

    def __getitem__(self, idx):

```

## 1.5 Training the Model

Training consists of repeatedly presenting mini-batches of SMS messages to the neural network and updating the model parameters using backpropagation. During training, we monitor both the **loss** and **accuracy** on the training and test datasets. After each epoch, these metrics are stored in four lists so that they can later be visualized as learning curves.

First, we define a function that computes the classification accuracy for a mini-batch.

```python
def accuracy_fn(y_true, y_pred):

    predictions = (y_pred >= 0.5).float()

    correct = (predictions == y_true).sum().item()

    accuracy = correct / len(y_true)

    return accuracy
```

Next, we train the model for 10 epochs. At the end of each epoch, the model is evaluated on the test dataset, and the loss and accuracy values for both the training and test sets are stored for later visualization.

```python
def train_model(model, train_loader, test_loader, epochs=10):

    # Store the training history
    train_losses = []
    test_losses = []
    
    train_accuracies = []
    test_accuracies = []
    
    num_epochs = epochs
    
    for epoch in range(num_epochs):
    
        # -----------------------
        # Training phase
        # -----------------------
        model.train()
    
        running_loss = 0.0
        running_accuracy = 0.0
    
        for inputs, labels in train_loader:
    
            optimizer.zero_grad()
    
            # Forward pass
            outputs = model(inputs).squeeze()
    
            # Compute loss
            loss = criterion(outputs, labels)
    
            # Compute accuracy
            accuracy = accuracy_fn(labels, outputs)
    
            # Backpropagation
            loss.backward()
    
            # Update model parameters
            optimizer.step()
    
            running_loss += loss.item()
            running_accuracy += accuracy
    
    
        # Average training metrics
        epoch_train_loss = running_loss / len(train_loader)
        epoch_train_accuracy = running_accuracy / len(train_loader)
    
    
        # -----------------------
        # Evaluation phase
        # -----------------------
        model.eval()
    
        test_loss = 0.0
        test_accuracy = 0.0
    
        with torch.no_grad():
    
            for inputs, labels in test_loader:
    
                outputs = model(inputs).squeeze()
    
                loss = criterion(outputs, labels)
    
                accuracy = accuracy_fn(labels, outputs)
    
                test_loss += loss.item()
                test_accuracy += accuracy
    
    
        # Average test metrics
        epoch_test_loss = test_loss / len(test_loader)
        epoch_test_accuracy = test_accuracy / len(test_loader)
    
    
        # Store metrics
        train_losses.append(epoch_train_loss)
        test_losses.append(epoch_test_loss)
    
        train_accuracies.append(epoch_train_accuracy)
        test_accuracies.append(epoch_test_accuracy)
    
    
        print(
            f"Epoch [{epoch+1}/{num_epochs}] "
            f"Train Loss: {epoch_train_loss:.4f} "
            f"Train Accuracy: {epoch_train_accuracy:.4f} "
            f"Test Loss: {epoch_test_loss:.4f} "
            f"Test Accuracy: {epoch_test_accuracy:.4f}"
        )

    return train_losses, test_losses, train_accuracies, test_accuracies

train_losses_FFNN, test_losses_FFNN, train_accuracies_FFNN, test_accuracies_FFNN = train_model(
    model = model_FFNN,
    train_loader = train_loader,
    test_loader = test_loader,
    epochs=10
)
```

During each training iteration, the model performs the following operations:

1. Receives a mini-batch of SMS messages.
2. Computes the predicted spam probabilities.
3. Calculates the binary cross-entropy loss.
4. Computes the classification accuracy for the current mini-batch.
5. Computes the gradients using backpropagation.
6. Updates the model parameters using the Adam optimizer.
7. Accumulates the loss and accuracy values for the current epoch.

After all mini-batches have been processed, one **epoch** is complete. The average training loss and accuracy are computed by averaging the values obtained from all mini-batches. The model is then evaluated on the test dataset to measure its generalization performance. Finally, the training and test loss and accuracy values are stored in the `train_losses`, `test_losses`, `train_accuracies`, and `test_accuracies` lists. These stored values can be used to plot learning curves, making it easier to visualize the model's performance over successive epochs and to identify potential overfitting or underfitting.

## 1.7 Evaluating the Model

After training, we evaluate the classifier using the test dataset. During evaluation, gradients are not required, making the process both faster and more memory-efficient.

```python
def evaluate(model):
    
    model.eval()
    
    correct = 0
    total = 0

    with torch.no_grad():

        for inputs, labels in test_loader:
    
            outputs = model(inputs).squeeze()
    
            predictions = (outputs >= 0.5).float()
    
            total += labels.size(0)
    
            correct += (predictions == labels).sum().item()
    
    accuracy = correct / total

    print(f"Test Accuracy: {accuracy:.4f}")

evaluate(model_FFNN)
```

The model produces a probability for each SMS message. A threshold of **0.5** is used to assign class labels:

* Probability **≥ 0.5** → **Spam (1)**
* Probability **< 0.5** → **Ham (0)**

The final classification accuracy is computed as

$[
\text{Accuracy} =
\frac{\text{Number of Correct Predictions}}
{\text{Total Number of Samples}}
]$

which measures the proportion of correctly classified messages in the test dataset.


## 1.8 Predicting the Class of a New SMS Message

Once the model has been trained, it can be used to classify previously unseen SMS messages. This process is called **inference** or **prediction**. During inference, the model receives a new text message, converts it into a sequence of token IDs, transforms the tokens into word embeddings, and finally predicts the probability that the message belongs to the **spam** class.

The prediction pipeline is illustrated below.

```text
New SMS Message
        ↓
Tokenization
        ↓
Token IDs
        ↓
Embedding Layer
        ↓
Feed-Forward Neural Network
        ↓
Spam Probability
        ↓
Predicted Label
```

The following example predicts the class of a new SMS message.

```python
import torch

# A new SMS message
text = "Hi, you win 10000$. Send me your card information."

def predict(text, model):
    # Set the model to evaluation mode
    model.eval()

    with torch.no_grad():

        # Convert the text into token IDs
        x = vectorize(text)

        # Add a batch dimension
        x = x.unsqueeze(0)

        # Predict the probability of spam
        probability = model(x).item()
    
        # Convert the probability into a class label
        prediction = "spam" if probability >= 0.5 else "ham"

    print(f"Message     : {text}")
    print(f"Probability : {probability:.4f}")
    print(f"Prediction  : {prediction}")

predict(text, model_FFNN)
```

A typical output is shown below.

```text
Message     : Hi, you win 10000$. Send me your card information.

Probability : 0.9987
Prediction  : spam
```

### Understanding the Prediction

The model produces a probability between **0** and **1**.

* A probability close to **1** indicates that the message is likely to be **spam**.
* A probability close to **0** indicates that the message is likely to be **ham**.

In this tutorial, we use a **decision threshold of 0.5**.

```text
Probability ≥ 0.5  →  Spam

Probability < 0.5  →  Ham
```

In the previous example, the predicted probability is **0.9987**, meaning that the model is highly confident that the message is spam. This prediction is reasonable because the message contains words and phrases that frequently appear in spam messages, such as **"win"**, **"10000$"**, and **"Send me your card information."**
